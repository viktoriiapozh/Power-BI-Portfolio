# Academic Performance & Time Intelligence Dashboard

**Tools:** Power BI, DAX, Power Query

📝 Project Description
Development of an analytical solution for a comprehensive assessment of academic performance over the academic year, calculating complex student grade distribution metrics, and identifying hidden patterns in the learning process.

🛠️ My Tasks
* Data import, relationship configuration, and building a star schema data model.
* KPI calculation using advanced DAX measures and Time Intelligence functions.
* Implementation of analytical reference lines (Trend lines, Percentiles) for deep data insights.
* Customization of the report's visual interface in accordance with modern UI/UX standards.

📊 Results
Created a multi-page interactive dashboard for monitoring student performance. Provided a tool for rapid anomaly identification across academic periods and automated the calculation of cumulative totals.
