# Academic Performance & Time Intelligence Dashboard

**Інструменти:** Power BI, DAX, Power Query

📝 Опис проєкту
Розробка аналітичного рішення для комплексної оцінки академічної успішності за навчальний рік, розрахунку складних метрик розподілу оцінок студентів та виявлення прихованих закономірностей у навчальному процесі.

🛠️ Мої завдання
* Імпорт даних, налаштування зв'язків та побудова зіркоподібної моделі даних.
* Розрахунок KPI за допомогою розширених мір мовою DAX та функцій Time Intelligence.
* Впровадження аналітичних ліній (Trend lines, Percentiles) для глибокого аналізу результатів.
* Кастомізація візуального інтерфейсу звіту відповідно до сучасних UI/UX стандартів.

📊 Результат
Створено багатосторінковий інтерактивний дашборд для моніторингу успішності студентів. Надано інструмент для швидкого виявлення аномалій у навчальних періодах та автоматизовано розрахунок накопичувальних підсумків.
